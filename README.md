# Journal Project

A small Cloudflare Pages-ready planner with:

- A monthly calendar with day notes
- Month-specific goal sections
- A simple journal and gratefulness log
- Browser local storage persistence

## Run locally

Open `public/index.html` directly, or run a static server from the `public` folder.

## Deploy to Cloudflare Pages

Deploy this folder as a static Pages project. The included `wrangler.jsonc` points Pages at `public` as the build output.
